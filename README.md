# Hive Mind — Interactive Bee Swarm Simulation

**Status:** Early working prototype. This is an independent software experiment, not the full proposed biometric installation.

Hive Mind explores how simple local rules among autonomous virtual bees can produce emergent collective behavior.

## Run
Open `index.html` in a modern browser. No installation, account, or API key is needed.

## Current features
- Animated bee-like agents using separation, alignment and cohesion rules
- Click or tap to change their attraction target
- Adjustable population, pause/resume, reset
- Runs locally; no external network calls or personal data

## Potential next steps
- Better flocking and avoidance algorithms
- Obstacles, flowers and foraging behaviors
- Deterministic tests and performance benchmarks
- UI for experimentation and visualization
